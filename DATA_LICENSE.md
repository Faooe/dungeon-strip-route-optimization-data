# Lisensi data penelitian

Data hasil eksperimen, tabel data, gambar analisis, dan dokumentasi penelitian
dalam repositori ini tersedia dengan lisensi
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).
Kredit pencipta: Faooe, pemilik repositori Dungeon Strip.

Lisensi MIT pada `LICENSE` berlaku untuk kode perangkat lunak (`.js`, `.mjs`,
dan `.py`). Lisensi CC BY 4.0 ini berlaku untuk data (`.csv`, `.json`,
`.jsonl`), gambar penelitian (`.png`), dan dokumentasi (`.txt`, `.md`).
Naskah artikel Word/PDF tidak termasuk dalam repositori atau kedua pemberian
lisensi di atas. Aset grafis, audio, dan font game juga tidak disertakan.

Saat menggunakan data, cantumkan nama pencipta, judul repositori, versi rilis,
tautan ke repositori, dan tautan lisensi. Tandai jika data diubah.
